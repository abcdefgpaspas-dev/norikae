# マイ乗換（自分専用・広告なし乗換アプリ）

阪急 正雀⇔茨木市／正雀⇔北千里（淡路乗換）用のPWA。iPhoneのホーム画面に追加して使う。

- 公開URL: https://abcdefgpaspas-dev.github.io/norikae/ （noindex）
- 通知：Google Apps Script（`gas/Code.gs`）＋ LINE公式アカウント「みどりのかご」(Messaging API)

## 機能

| 機能 | どこで |
|---|---|
| 出勤モード（ワンタップで次の便・到着時刻・カウントダウン／出勤⇔帰宅切替） | ホーム上部 |
| 保存ルート・★お気に入り・ルートメモ | ホーム／ルート画面 |
| 今から／出発時刻／到着時刻指定、1本前・1本後、乗換待ち時間 | ルート画面 |
| 停車駅・各駅の時刻・種別 | ルート画面で便をタップ |
| 始発・終電、IC運賃 | ルート画面 |
| 駅時刻表（平日／土休日 自動切替・祝日／年末年始対応） | 時刻表タブ |
| 乗換アラーム（LINE、発車前／乗換駅到着前／乗換発車前／到着前） | 「この便で行く」 |
| 遅延通知（平日 6:00-9:30・17:00-20:30に5分おき確認、同じ内容は再送しない） | GAS → LINE |
| 迂回ルート（JR岸辺⇔茨木・バス・地図リンク）、運行情報 | 迂回タブ |
| 構内図リンク・号車／出口メモ | 駅タブ |

## しくみ

```
iPhone(PWA) ──GET──▶ GAS ウェブアプリ ──▶ 阪急公式の駅時刻表・列車詳細ページ（毎日3時に変更チェック）
     │                 ├─▶ 阪急 運行情報ページ（5分おき）
     │                 └─▶ LINE Messaging API（アラーム・遅延通知）
     └── routes.json（ルート・駅・迂回の設定。GASもこれを読む）
```

時刻表データはリポジトリに入れていません（阪急サイトの時刻表は再配布禁止のため）。
GASが公式ページから取得して自分のアプリにだけ返します。

## ダイヤ改正のとき

**基本は何もしなくてOK。** GASが毎日3時に駅時刻表ページを確認し、変わっていれば自動で作り直します。
すぐ反映したいときは アプリの 設定 →「GAS側で時刻表を作り直す」→ 数分後「時刻表を再取得」。

## ルートを追加する

`routes.json` の `routes` に1件追加してコミット → アプリ設定の「GAS側で時刻表を作り直す」。

```json
{
  "id": "shojaku-umeda",            // 英数字の一意な名前
  "name": "正雀 → 大阪梅田",
  "fareIC": 280,
  "legs": [
    { "id": "shojaku_umeda", "line": "阪急京都線", "from": "正雀", "to": "大阪梅田",
      "page": "HK-66_ky_1", "types": ["普通"] }
  ]
}
```

- `page` は阪急公式の駅時刻表URL `https://www.hankyu.co.jp/station/html/HK-66_ky_1_w.html` の `_w.html` を除いた部分
  （駅ページ → 時刻表 → 方面 → 平日 を開いてURLを見る）
- `from` / `to` は阪急サイトの表記どおりの駅名
- `types` は乗る種別で絞り込み（省略可。省くと全種別を調べるので時間がかかる）
- 乗換があるルートは `legs` を2つ以上並べる（乗換時間は設定画面の「最低乗換時間」）
- 駅時刻表タブに出したい駅は `timetables` に追加

## GASのセットアップ（初回のみ）

1. https://script.google.com で新しいプロジェクト「マイ乗換」→ `gas/Code.gs` を貼り付けて保存
2. プロジェクトの設定 → スクリプト プロパティに追加
   - `LINE_TOKEN`：みどりのかごのチャネルアクセストークン（既存GASのプロパティ、またはLINE Developers → Messaging API設定）
   - `LINE_USER_ID`：自分のユーザーID（LINE Developers → チャネル基本設定 →「あなたのユーザーID」）
3. 関数 `setup` を実行 → 権限を承認（時刻表の取得が始まる。数分かかる）
4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」／実行ユーザー「自分」／アクセス「全員」→ デプロイ
5. 関数 `sendSetupLink` を実行 → LINEに届いたリンクのURLをアプリの 設定 → GAS URL に貼って保存
6. 設定 →「LINEテスト」で届けばOK

GASを書き換えたら「デプロイを管理 → 編集 → 新バージョン」で同じURLのまま更新。

## 注意

- 時刻表は公式の駅時刻表ベース。臨時ダイヤ・遅延は反映されない
- 阪急の運行情報は「20分以上の遅れ」のみ公表
- アラームはGASの1分トリガーなので ±1分程度ずれる
- LINE無料プランは月200通（みどりのかごと共通）
- 遅延チェックの時間帯・曜日は `gas/Code.gs` の `CONFIG.DELAY_WINDOWS` で変更
